# Публичный снимок R117

Файлы прочитаны с дачапар.рф 04.11.2026 и сохранены без изменения байтов. Это воспроизводимая основа отдельного прототипа; она не заменяет исходный модуль в `web/` и не публикуется автоматически.

`metadata.json` хранит SHA-256 снимка и общих зависимостей из `web/`. Текущий публичный `catalog-pricebook.json` совпал с репозиторным по байтам, поэтому второй файл книги цен не создаётся. В снимке квиза есть действующие публичные 20 значений «Делюкса»; они совпали с Google-калькулятором при чтении 04.11.2026. Не править суммы в этом снимке для устранения расхождений: следующая интеграция должна получать конечные цены из общей утверждённой ведомости.

Настройки сервера, токены, база заявок и приватные затраты в этот каталог не входят. Аналитический модуль скопирован без изменения; локальный сервер отключает аналитику через настройки просмотра.
