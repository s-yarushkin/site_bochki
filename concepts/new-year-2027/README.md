Публикация с другого ПК: [пошаговая инструкция, проверка и откат](../../docs/NEW_YEAR_2027_RELEASE.md).

он добавляет только маршрут `/novyy-god/` к активному выпуску сайта.

Обновлено 02.11.2026: один праздничный экран, четыре переключаемые модели, размеры и цены действующего «Комфорта», закреплённый телефон и CTA, существующий путь /api/lead с уведомлением в MAX.

## Сборка и просмотр

Сборка: Python 3 + Pillow, команда из корня репозитория: python scripts/build-new-year.py. Результат: output/new-year-2027-site/novyy-god/. Это отдельный маршрут, который накладывается после актуальной сборки сайта. Основную страницу и API пакет не заменяет.

Локальная проверка: node concepts/new-year-2027/preview.mjs, затем http://127.0.0.1:4187/novyy-god/ . Локальный сервер использует квитанции в памяти; сообщения в MAX не отправляет и не читает токены. При публикации используются действующие модули сайта и настройки /data/site-settings.json. Остановка — Ctrl+C. Открытие HTML через file:// подходит только для статичного осмотра: модульная форма требует HTTP.

## Материалы

- CONCEPT.md — исследование, оффер, сценарий.
- DESIGN.md — палитра, шрифты, лицензии.
- BRIEF.md — исходное задание.
- PROMPTS.json — запросы ImageGen.
- lead.mjs — форма, использующая общий клиент сайта, маску телефона и аналитику.
- lead-contract.mjs — стандартный quote выбранной модели и размера с комментарием «Новый год 2027»; callback сохранён для совместимости.
- VERIFICATION.md — проверка и текущий статус.

На домен пока не опубликовано. Шрифты PP и безусловные сроки акции не добавлены. Серверное уведомление в MAX работает существующим способом: здесь нет нового бота, получателя или прямой ссылки в мессенджер.

Дополнительно: catalog.mjs использует общий движок цен, models.mjs управляет выбором; MODEL-PROMPTS.json содержит три новые зимние сцены. Второй и третий блоки удалены из DOM и из пакета.

Обновление праздничного оформления: CTA «Пришлите мне варианты планировок и комплектаций», мерцающие гирлянды, плавные переливы модельных кнопок, новогодняя форма с выбранной моделью. Кнопка снега убрана. countdown.mjs считает дни/часы/минуты до 01.01.2027 00:00 МСК; тесты — tests/new-year-countdown.test.mjs. Пакет теперь содержит 23 файла.
