# Общие входы и дневные отчёты

7 ноября 2026 года база содержала четыре визита и 45 событий за 6 ноября.
За 7 ноября записей визитов и событий не было. Последнее событие было
сохранено 6 ноября в 21:13 по Москве. Старый показатель технических переходов
учитывал запросы к коротким ссылкам, а визиты и действия зависели от согласия.
На присланном скриншоте Директа был 21 рекламный клик.

Новый общий показатель считает внешние переходы и прямые открытия публичных
страниц. Переходы внутри сайта и обновления страницы пропускаются.
Входы по подписанным ссылкам из конструктора составляют часть общего числа.
Суммы сохраняются по дню, странице и источнику без IP, идентификатора
браузера и истории посетителя. Сбор использует JavaScript и не равен числу
уникальных людей или рекламных кликов.

После входа в кабинет браузер получает функциональную отметку исключения
команды на год. Её можно переключить в отчётах. Каждый рабочий браузер,
включая телефон, нужно отметить отдельно. Очистка cookies удаляет отметку.
Старая история задним числом не пересчитывается.

Оба отчёта открываются за сегодня по Москве. Быстрые кнопки меняют обе даты
и сразу обновляют отчёт. Общий счётчик показывает время начала сбора.
Подробные действия и ответы квиза продолжают учитываться по согласию.

Локальные проверки охватывают HTTP API с временной SQLite, подписанные
ссылки, исключение команды и ботов, защиту Origin, границу суток по Москве,
отсутствие записей посетителей при общем подсчёте и сохранение квиза после
согласия. Проверены отчёты в Chrome при ширине 1440 и 375 пикселей.
Отправка заявок проверена через виртуальную доставку во всех четырёх каналах.

Установщик создаёт копии текущих выпусков сайта и API. В базе добавляются
только таблицы суммарного счётчика. Таблицы заявок не заменяются.
При ошибке публичных проверок оба выпуска возвращаются целиком.
Перед публикацией сверяются исходные хеши и синтаксис модулей.
