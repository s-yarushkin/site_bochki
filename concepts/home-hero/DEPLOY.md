# ДачаПар · первый экран, каталог и 14 планировок

Сборка рассчитана на выкладку поверх текущего статического выпуска. Пакет включает
главную, четыре страницы моделей, маршрут `/planirovki/` и ресурсы в `/home-hero/`. Прайс, квиз, заявки
и остальные страницы берутся из выпуска на сервере.

1. Снимите копию действующего выпуска и зафиксируйте путь для отката. Возьмите из
   этого выпуска `index.html`, `data/catalog-pricebook.json` и четыре файла
   `bani/<модель>/index.html`.
2. В корне репозитория установите Pillow и соберите пакет из этих двух файлов.

   ```sh
   python -m pip install Pillow
   python concepts/home-hero/build.py --release --home-baseline /path/to/current/index.html --model-baseline /path/to/current --pricebook /path/to/current/data/catalog-pricebook.json
   ```

   Сборка проверит структуру главной, совпадение стартовых цен и соответствие
   габаритов планировок размерам прайса. При ошибке проверьте разницу с текущей
   версией сайта до повторной сборки. Готовые файлы находятся в
   `output/home-hero-release.zip`, их контрольные суммы — в `manifest.json`.
3. Наложите содержимое `site/` из ZIP на копию действующего выпуска. Убедитесь,
   что сервер отдаёт JavaScript-модули с MIME JavaScript, а GLB с
   `model/gltf-binary` или `application/octet-stream`. Если используются
   правила переписывания URL для `/planirovki/`, проверьте, что запрос получает
   новый `planirovki/index.html`. Корневой `index.html` сохраняет правила
   индексирования из серверной главной.
4. На тестовом адресе проверьте маршрут от первого экрана до каждой из четырёх
   моделей, независимую смену цены и примера, увеличение чертежа, открытие,
   вращение и закрытие 3D. Откройте `/planirovki/?model=viking` и
   `/planirovki/`. Проверьте блок примеров на четырёх отдельных страницах моделей
   и откройте главную на телефоне.
5. Отправьте согласованную тестовую заявку через серверное окружение и проверьте
   доставку в MAX. В заявке должны быть источник «карточка модели», модель,
   выбранный для расчёта размер и отдельный код примера `DP3D-XX`.
6. Переключите трафик на проверенный выпуск штатным способом. При откате
   переключите трафик на сохранённый выпуск целиком.

Для локального просмотра выполните `python concepts/home-hero/build.py` и
`node concepts/home-hero/preview.mjs`. Это режим проверки интерфейса с
отключённой аналитикой и заблокированной отправкой заявок.

Комплект новой планировки состоит из SVG, GLB, статичного WebP и спецификации
JSON. Добавляйте их вместе с записью в `layouts/index.json`, сохраняя
существующие коды. CSV в `layouts/specs/` предназначены для работы с составом
и будущей калькуляцией. Высоты и прочие допущения инженера указаны внутри
спецификации. Цены на карточке относятся к комплектациям выбранного размера.
