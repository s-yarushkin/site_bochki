# Версия 3 — интерфейс сайта вместо рекламного плаката

Архив дизайна. Актуальный просмотр — ../v4/index.html. Цифры на старом
mockup-v3.png устарели; для публикации использовать ../v4/mockup-v4.png.

Открыть **index.html** обычным браузером; отдельный сервер не нужен.
**mockup-v3.png** — визуальный макет направления. Изображения сгенерированы встроенным
инструментом; запросы сохранены в prompts.json. Цены и надписи в HTML-прототипе
являются обычными объектами страницы, не частью изображения.

## Согласованное направление
- Светлый павильон, чёрная баня, художник, заголовок за крышей сохранены.
- Выбор одной из четырёх моделей и размера; обе комплектации видны одновременно.
- Две карточки с полными описаниями из текущего основного сайта.
- В каждой: зачёркнутая цена вне акции, обычная строка скидки и итог с «от».
- В текущем расчёте участвует только скидка Чёрной пятницы.
- Спокойная типографика Manrope, цены обычного размера, без рекламных лозунгов.
- Одна основная CTA и существующий по смыслу вход в сравнение комплектаций.

## Что работает в прототипе
Модели, размеры, выбор комплектации, 40 цен, сохранение размера при возврате к
модели, смена изображения на соответствующую баню, сравнение полного состава,
открытие и закрытие формы, Escape и возврат фокуса. Адаптация под узкий экран.
Форма демонстрационная: ввод остаётся в браузере, отправка в API/MAX не выполняется.
Рабочий сайт, прайсы и серверные обработчики не менялись.

Исходный выбор — Парус 5,5 м, соответствующий приведённому владельцем примеру.
Действующий исходный прайс 525 000 / 654 000 ₽; по ранее заданным формулам:
- Комфорт: прайс вне акции 550 000, скидка 30 000, итог 520 000 ₽.
- Делюкс: прайс вне акции 684 000, скидка ЧП 35 000, итог 649 000 ₽.

Зачёркнутая сумма — проект нового прайса вне акции, не утверждение об истории продаж.
Текущие формулы не заменены приведённым в сообщении примером оформления.
Период договора 11–21 ноября 2026 включительно по московскому времени сохраняется.

## Проверки
`node --test tests/black-friday-preview.test.mjs`: все 40 позиций, отсутствие
дополнительной скидки, отсутствие чужого размера/цены при смене модели,
пример Парус 5,5 м. Синтаксис JS и наличие локальных ресурсов проверяются отдельно.
Визуальный макет не является снимком автоматического теста HTML в браузере.
