# Что будет после заявки

В локальной главной после подтверждённой отправки общая форма меняется на
сообщение с тремя шагами: связь с менеджером, подбор и согласование условий,
отправка договора, если условия подходят. Кнопка: «Хорошо, буду ждать».
Каждый шаг сопровождает отдельная SVG-иконка; сообщение занимает тот же dialog.
По уточнению пользователя сообщение закрывается только нижней кнопкой:
крестик скрыт, Escape и клик по фону его не закрывают. В исходной форме
закрытие крестиком, Escape и кликом по фону сохранено.

Доступно для общей формы главной, включая плавающую CTA и нижнюю кнопку.
Сообщение появляется только после штатной проверки submitLead: ok=true,
delivered=true, analytics.persisted=true. При ошибке сохраняется исходная форма.
После закрытия и повторного открытия показывается новая форма; фокус возвращается
на кнопку открытия. Фокус после успеха переводится на заголовок сообщения.
