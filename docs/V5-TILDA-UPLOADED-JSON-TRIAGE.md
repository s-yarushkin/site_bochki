## Артефакты предварительного разбора

На рабочей стороне сформированы **`photo-contact-sheet.html`**, **`photo-review.csv`** и JSON анализа. Они существуют как файлы текущей сессии, а не как коммит GitHub и не являются доказательством просмотра самих изображений. HTML обращается к исходному HTTPS CDN для отображения картинок; возможны ограничения сети.

## Офлайн-экспорт, который позволяет сделать визуальную приёмку

После обновления этой ветки:

```powershell
node ops/export-tilda-photo-review.mjs --input "$env:TEMP/garant-bani-tilda-media-candidates.json" --output "$env:TEMP/GB-V5-photo-review"
```

Экспортёр:
- скачивает только фотографии с `https://static.tildacdn.com` (allowlisted);
- не следует за редиректами, не принимает неподходящие MIME/сигнатуры, ограничивает размер одного файла 16 MiB;
- группирует 36 ссылок, встретившихся только на одной странице; не переиспользует общие изображения как фото модели;
- создаёт `photos/`, `index.html` и `review.json` с SHA-256, статусом и источником;
- все материалы остаются **INTERNAL_REVIEW_ONLY_NOT_PUBLISHABLE**;
- не пишет ничего в код и не отправляет ничего в GitHub/MAX/действующий сайт.

После запуска архив папки можно передать на ручную визуальную сортировку. **Это не согласование прав на публикацию.**
