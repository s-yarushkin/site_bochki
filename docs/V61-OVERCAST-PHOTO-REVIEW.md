Реальная геометрия бани не заменена выдуманной. Газон и деревянные дорожки в `hero-sun.webp` — визуализация, явно раскрыта на сайте. Права на исходные изображения и коммерческие данные остаются **PENDING_OWNER_CONFIRMATION**.

## Атмосфера

- Удалены все `.atmos-rain` из HTML/CSS/JS, `v6-rain-fall`, штриховка и капли.
- Одна глобальная пара размытых CSS cloud-bank слоёв **за** всеми секциями и фотографиями.
- Скролл обновляет CSS-переменную с ограниченным параллаксом; дрейф медленный и без рывков.
- `prefers-reduced-motion` / `visibilitychange` отключает движение облаков; смена погоды переключает только одобренные два кадра «Квадро Хаус», без графических осадков поверх фото.
- Две погодные вставки сохраняются, но тексты и сетка исправлены.

## Дизайн-ритм

- Сетка: desktop до 1200px + минимум 40px по краям; tablet 24px; mobile 16px.
- Удалён `width:100%` у `.weather-window-content`; исправлена фактическая причина прилипания текста.
- Секции: 88/70/56px по высоте, с уплотнением mood/pain/delivery/FAQ и атмосферных переходов.
- Финальный CTA: одобренная композиция, градиент, тексты и кнопки сохранены; у SUN заменён только фоновый файл на согласованный `hero-sun.webp`. Footer и менеджерские экраны не менялись.
