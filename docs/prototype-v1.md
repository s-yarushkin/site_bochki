# Гарант Бани · прототип V1 (08.10.2026)

## Позиционирование
Готовая баня для дачи — отдых на выходных без затяжной стройки и строительного мусора на участке. Сценарий: приехали на дачу, растопили баню, отдыхаете с близкими. Эмоциональный контраст: солнце или дождь за окном, внутри — тепло.

## Что реализовано
- Адаптивный первый экран с переключением «Солнце / Дождь» и разным копирайтом.
- Каталог: Квадро Хаус, Квадро, Парус, Викинг. Фильтрация карточек.
- Блок «Изготовили — привезли — установили — подключили — пользуетесь».
- Блоки эмоции, интерьеров, FAQ, CTA.
- Интерактивный подбор модели, длины и опций; формирование запроса для менеджера и копирование.
- Мобильная навигация и закреплённая CTA.

## Достоверность
1. `assets/sunny.webp`, `assets/rain.webp` и `assets/interior-*.webp` — AI-концепты по реальным образцам, НЕ фотографии выполненных работ.
2. `assets/real-*.webp` — обработанные фотографии, предоставленные заказчиком. До публичного запуска подтвердить конкретную модель/SKU каждого снимка и право публикации.
3. Прайс дополнительных работ от 06.02.2026 содержит дилерские цены, их не выводим как розничные.
4. Возможность использовать баню в день установки зависит от готового основания, подключения, комплектации и условий доставки; скорость нагрева не обещаем без заводского подтверждения.
5. Форма заявки в V1 не отправляет персональные данные на сервер; она лишь копирует текст. Телефон: +7 911 440-32-24 — из официального сайта.
6. Не публиковать в качестве production-сайта до подтверждения цены, комплектаций, гарантий, условий доставки и приёма заявок.

Статический сайт без сборки: откройте `index.html` или раздайте каталог через любой HTTP static server. Шрифты загружаются через Google Fonts; предусмотрены системные fallback.
