# Новогодняя страница: публикация с другого ПК

Адрес после выкладки: **https://дачапар.рф/novyy-god/**. PR сам сайт не публикует.

Один экран с четырьмя моделями, зимними сценами, размерами, ценами действующего «Комфорта»,
московским отсчётом и праздничной формой. Заявка использует существующие общие модули
и `/api/lead`; уведомление менеджеру в MAX выполняет действующий сервер.
Пакет добавляет только `/novyy-god/`. Главная, общие цены, API, настройки, база и секреты
не изменяются. Страница пока `noindex,nofollow`: отдельный рекламный маршрут, без добавления в Sitemap.
Визуализации созданы для акции; конкретный срок изготовления подтверждает менеджер.

## 1. Получить ветку и собрать

На ПК с Git, Python 3.10+, Node.js 24 и SSH-доступом к `deploy@135.106.137.195`:

```powershell
git clone --branch codex/new-year-2027-landing https://github.com/s-yarushkin/site_bochki.git site-bochki-new-year
cd site-bochki-new-year
python -m pip install Pillow==12.0.0
node --test tests/new-year.test.mjs tests/new-year-countdown.test.mjs tests/analytics.test.mjs tests/pricing-parity.test.mjs
python tests/new-year-release.test.py -v
python scripts/build-new-year.py
python output/new-year-2027-deploy/new-year-remote.py --verify-payload
```

Если checkout уже есть, переключитесь на эту ветку в чистой рабочей копии и выполните
`git pull --ff-only`. Локально: `node concepts/new-year-2027/preview.mjs`, затем
http://127.0.0.1:4187/novyy-god/ . Остановка — Ctrl+C. Это тестовая форма в памяти,
реальные сообщения в MAX не отправляются.

Результаты сборки (в Git не хранятся):

- `output/new-year-2027-site/novyy-god/` — только файлы страницы.
- `output/new-year-2027-route.zip` — только этот маршрут; нельзя заменить им весь сайт.
- `output/new-year-2027-handoff.zip` — тот же маршрут + манифест и установщик.

В CI workflow **New Year landing handoff** строит тот же архив и сохраняет его
в артефакте `dachapar-new-year-2027-handoff`. После успешного CI можно скачать артефакт
вместо локальной сборки; проверяйте, что он относится к нужному коммиту PR.

## 2. Передать архив и проверить сервер

В PowerShell из корня checkout:

```powershell
ssh deploy@135.106.137.195 "mkdir -p /tmp/dachapar-new-year-2027"
scp output/new-year-2027-handoff.zip deploy@135.106.137.195:/tmp/dachapar-new-year-2027/
ssh deploy@135.106.137.195 "cd /tmp/dachapar-new-year-2027 && python3 -m zipfile -e new-year-2027-handoff.zip . && python3 new-year-remote.py --check"
```

Нужен результат `CHECK=PASS`. Проверка сверяет состав и SHA-256 пакета, наличие действующих
модулей и здоровье API. Она сохраняет в `/tmp` снимок файлов активного выпуска, но сайт
не переключает. При отсутствии модуля или уже существующем `/novyy-god/` установка
останавливается. Не запускайте параллельно другие выкладки сайта.

## 3. Опубликовать

```powershell
ssh -t deploy@135.106.137.195 "cd /tmp/dachapar-new-year-2027 && sudo python3 new-year-remote.py --apply"
```

Sudo-пароль вводится только в терминале. Установщик повторно сверяет снимок, копирует
текущий выпуск, добавляет маршрут и атомарно переключает `current` на новый выпуск
`NY2027-…`. Все остальные файлы должны сохранить свои хеши. Никаких перезапусков API
или изменений его базы не выполняется. Если сайт изменился после Check, сначала
повторите Check. Установщик требует новую папку выпуска и не перезаписывает прошлые попытки.

После переключения установщик проверяет все файлы нового маршрута через домен и здоровье
существующего API. При ошибке этой проверки возвращает прежний указатель автоматически.
Успех — строка `DEPLOYED=…/novyy-god/`. Это проверка доставки файлов, а не реальная отправка заявки.

Откройте страницу на телефоне и ПК, переключите модели и размер, откройте форму.
При проверке доставки в MAX используйте согласованную владельцем тестовую заявку:
установщик сам реальных обращений не отправляет.

## Откат

Успешный Apply выводит полную команду `ROLLBACK: sudo python3 … --rollback …/state.json`.
Сохраните её. Подключитесь к серверу `ssh -t deploy@135.106.137.195` и выполните эту команду.
Откат проверяет, что активен именно новогодний выпуск и его файлы не изменились,
после чего возвращает предыдущий выпуск. При наличии более новой выкладки откат
останавливается. Новые заявки и база сохраняются. Папку `/tmp/dachapar-new-year-2027`
с установщиком оставьте до завершения акции.
