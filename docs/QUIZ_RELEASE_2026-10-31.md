**Скачать проверенный ZIP:** [GitHub Actions · quiz release handoff](https://github.com/s-yarushkin/site_bochki/actions/runs/41231206496/artifacts/13053403521) — в артефакте лежит один `DPQUIZ-a4c4ab3c1c6f-handoff.zip`, внутри него `manifest.json`, `payload.zip`, PowerShell-установщик, Python-установщик, программа публичной проверки и README.

## Какие файлы в выпуске

Изменяем **только**:
- WEB: `quiz.mjs`, `quiz-engine.mjs`, `quiz.css`, `data/quiz-v1.json` и **две вставки** в `index.html` для подключения этих файлов.
- API: новый `server/quiz-channel-policy.mjs` и **три строго проверяемых участка** существующего `server/garant-bani-relay.mjs`, чтобы принять `purpose=quiz_catalog` с выбранным MAX/WhatsApp/Telegram и передать это менеджеру.
- **НЕ** изменяем `data/catalog-pricebook.json`, калькулятор, существующие формы, юридические документы, секреты, реальную базу заявок или перечень комплектаций.

- `node --test tests/quiz-channel-policy.test.mjs` — три мессенджера и запрет расширения обычного callback.
- `python3 scripts/check-public.py` — статический сайт, ссылки, 39 изображений планировок, цены, юридические файлы.
- `tests/quiz-release.test.py` — точное применение минимальных патчей к исходному HTML/API, блокировка неизвестной версии API и пути файлов.
- `python3 scripts/build-quiz-v1-release.py` — пакет собирается с SHA256 для каждого файла, manifest и контрольными хешами неизменяемых файлов.

Ранее отдельный browser smoke квиза проверял 1440 / 390 / 320 px, 4 маршрута, в том числе конфликт спальни и помывочной, и все три варианта контакта **с заглушкой API**. Это **не** реальная отправка в кабинет менеджера.

**Условие NO GO:** если действующий сайт или API отличается от защищённых исходников/предполагаемой структуры — **не заменять хеши вручную** и не выключать проверки. Нужна новая сборка из актуальной версии production.

## Четыре шага на Windows

Скачать и распаковать ZIP артефакта, затем распаковать находящийся внутри ZIP `DPQUIZ-a4c4ab3c1c6f-handoff.zip` в отдельную папку. Открыть PowerShell в этой папке.

```powershell
# 1. Проверка действующего WEB/API; защищённые файлы — только чтение
powershell -NoProfile -ExecutionPolicy Bypass -File .\Quiz-V1-Deploy.ps1 -Mode Check

# 2. Копия активного WEB и API, патч нового выпуска, тест API в новой копии.
# Действующий сайт продолжает работать на старой версии.
powershell -NoProfile -ExecutionPolicy Bypass -File .\Quiz-V1-Deploy.ps1 -Mode Stage

# 3. После PASS: резервная копия SQLite и переключение симлинков WEB/API.
powershell -NoProfile -ExecutionPolicy Bypass -File .\Quiz-V1-Deploy.ps1 -Mode Apply

# 4. После успешного Apply: публичный HTTP GET без отправки заявок
python .\verify-quiz-public.py --manifest .\manifest.json
```

`Check` использует SSH без sudo; `Stage/Apply` запросят sudo-пароль в обычном терминале. Скрипты выполняются только через проверенный `deploy@135.106.137.195`; никаких паролей в коде/артефакте.

## Проверки ПОСЛЕ Apply

1. `QUIZ_DEPLOY=PASS`, проверено здоровье API `/health`. **Активный API и сайт обязаны быть одной версии**.
2. `QUIZ_PUBLIC_GET=PASS`: загружаются 4 ресурса квиза, 41 схема, публичный прайс **не изменён**.
3. На desktop/mobile пройти все 3 вопроса и открыть результат. Проверить **только одно** предложение получить каталог в конце, три кнопки MAX/WhatsApp/Telegram и один телефон; проверить, что браузер не выдаёт ошибок и не перекрыты CTA.
4. В согласованный момент отправить **одну тестовую заявку**, отметив её тестовой, и убедиться, что она сохранилась в кабинете менеджера, пришло MAX-уведомление, выбранный мессенджер указан и не создалась дубль-заявка. Это **не входит** в автоматические проверки — чтобы не засорять реальные обращения.
5. Проверить, что старая форма обратного звонка и калькулятор работают, а текущая публичная цена `Комфорт` не изменилась.
6. До выполнения этих пунктов **не запускать рекламу с новыми целями квиза**. Настроить и отслеживать подтверждённые заявки, не считать открытие квиза конверсией.

## Откат

После `Apply` установщик распечатает точную команду отката и путь `/var/backups/dachapar/DPQUIZ-.../state.json`. Можно запустить из той же папки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Quiz-V1-Deploy.ps1 -Mode Rollback -RollbackState '/var/backups/dachapar/DPQUIZ-a4c4ab3c1c6f/state.json'
```

Откат возвращает **только код**, не трогает и не восстанавливает старый SQLite — новые заявки остаются в БД. Если после выпуска кто-то уже переключил версии самостоятельно, откат остановится, чтобы не затереть чужие изменения.
