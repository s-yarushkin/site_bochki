# Обложка пересылаемой ссылки — зимний «Парус»

Выбран вариант 04: «Хорошо, когда баня своя». Изображение создано встроенным
image_gen по референсу актуального первого экрана «Парус»; это рекламная
визуализация. Точный промпт и остальные направления сохранены в
`concepts/social-preview-20261106/prompts.json`. Остальные три PNG для сравнения
лежат локально в `output/social-preview-20261106/`.

Рабочий файл: `web/assets/social/dachapar-parus-winter-20261106-v1.png`,
1732 × 908 px, PNG, 2 669 842 байта. Выбранный пользователем файл скопирован
побайтно; текст, композиция и подпись «дачапар.рф» уже включены в изображение.
Новый адрес файла используется для отделения новой обложки от старой картинки.

Обновляются только изображения Open Graph/Twitter и их метаданные в `index.html`:
`og:image`, HTTPS URL, MIME, размеры, alt, `twitter:card`, `twitter:image` и alt.
Действующие заголовок, описание, canonical, разметка SEO и видимая страница
сохраняются. Ссылки `/go/...` перенаправляют на эту же страницу и получают новую
обложку после повторного чтения метаданных сервисом. Сохранённые в мессенджере
старые карточки могут требовать обновления самим мессенджером.

В репозитории и действующем релизе разные сборки `index.html`. Поэтому при
публикации НЕ заменять действующую страницу целиком файлом из `web/`. Скрипт
`social_preview.py` накладывает только теги обложки на свежую действующую страницу.
Тело HTML сохраняется побайтно. Новые теги также внесены в репозиторный `web/index.html`
для последующих сборок.

## Проверка и публикация

1. `python tests/social-preview.test.py`: сохранение тела и остальных тегов,
   отсутствие дубликатов, повторный запуск без изменений, отказ без `<head>`.
2. `python scripts/build-social-preview.py`: снимает свежий инвентарь файлов через
   существующий SSH `dachapar`, получает публичный HTML, проверяет его хеш и размер
   PNG, собирает воспроизводимый архив из двух файлов в `.local/social-preview`.
3. Загрузить `deployment.json`, `payload.tar.gz`, `deploy-social-preview.py` и
   `social_preview.py` в `/tmp/dachapar-social-<release id>/`.
4. `python3 deploy-social-preview.py --check`: без изменения сайта сверяет весь
   инвентарь и накладывает архив на временную копию действующего web.
5. `scripts/publish-social-preview-window.py` открывает пользователю окно для
   sudo-пароля. Пароль остаётся только в памяти. Серверная часть `--apply` создаёт
   отдельный web-релиз, сохраняет предыдущий HTML, атомарно переключает symlink,
   проверяет публичные хеши страницы и изображения, MIME, `/go/`, кабинет и health.
   Все остальные web-файлы и весь API сверяются побайтно. Сервис не перезапускается;
   база, учётки, MFA, MAX и настройки сервера не открываются для изменения.

Откат: `sudo python3 deploy-social-preview.py --rollback` из каталога пакета.
Возвращается только предыдущий web symlink, после проверки актуального релиза/API.
База не восстанавливается и не изменяется. Автоматический откат выполняется при
ошибке проверок после переключения. Отчёт публикации не содержит секретов.

Свойства метаданных: [Open Graph protocol](https://ogp.me/).
