# Дача Пар — юридический релизный контроль (20.10.2026)
Статус: **NOT LEGALLY APPROVED / NO PRODUCTION DEPLOY**. Этот файл — внутренний чек-лист, не предназначенный посетителям. Юридическое утверждение выполняет фактический оператор данных с профильным юристом.

## Подтверждено исходниками
- В публичных документах оператор и продавец: ООО «ВУДАРТ-ГРУПП», ИНН 3500023844, ОГРН 1263500003590. Совпадение реквизитов с открытым ЕГРЮЛ-профилем само по себе не подтверждает договорных полномочий оператора именно на этот сайт.
- Новая форма должна иметь отдельный непредзаполненный checkbox. Сервер принимает `consent=true` + текущие `consentVersion` / `consentMethod`. SQLite хранит payload с `consentEvidence`, ID и временем создания обращения; исторические версии поддерживаются ради совместимости.
- Обращение сохраняется в SQLite и передаётся в группу MAX, доступную персоналу. Системного удаления/анонимизации записей и архива MAX в текущем коде нет.
- `index.html` загружает Google Fonts с внешних доменов. В ветке нет прямого подключения Яндекс Метрики, но на production она может быть интегрирована другими средствами. Проверить фактические сетевые вызовы.
- За отправкой следуют серверная валидация, ограничение частоты, авторизация менеджера. Этим не исчерпываются обязанности по защите ПДн.
