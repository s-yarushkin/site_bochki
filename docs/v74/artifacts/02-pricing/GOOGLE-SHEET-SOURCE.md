# V74-02 · Связка Google Sheet → публичный прайсбук → все точки сайта

## Единственный бизнес-источник
- Оригинальная Google Sheet, скрытая вкладка **Рабочий калькулятор**.
- Источник входных коммерческих данных — формулы G225:G244 (не публикуются).
- Добавленная пользователем колонка **H224 = Стоимость для сайта, округлённая**.
- Формула в H225:H244: `=IF(AND(ISNUMBER(G225),G225>0),CEILING(G225,5000),"")`.
- Запросы к публичному сайту не обращаются к приватной Google Sheet.
- Коммерческий снимок ТОЛЬКО 20 публичных H-значений хранится в `data/source/v74-public-rounded-sheet-snapshot.json`.
- Рантайм сайта/сервера опирается только на `data/catalog-pricebook.json`, который проверяется на полное равенство со снимком. Не допускается локальная «красивая» цена в карточках, отличающаяся от `quote-engine.js`/сервера.
- `scripts/verify-v74-public-prices.mjs` проверяет 20/20, отсутствие снижения относительно старого base, кратность 5000, независимость допов, корректность HTML первого кадра.
- `--live` сравнивает с оригинальной H225:H244 через **read-only OAuth**. Для GitHub Actions требуются секреты `DACHAPAR_SHEETS_ID` и `DACHAPAR_SHEETS_READ_TOKEN`; без них LIVE=NOT_RUN, не считать живую синхронизацию подключённой.
- Обновление Google Sheet не означает автоматическую смену стоимости в production: новая ревизия прайсбука обязательно проходит PR, согласование и безопасный деплой. Если Google H изменился, `--live` откажет пока не обновлён снапшот/версия.

## Срок действия и история
- Новая версия: `2026-10-19-v74-sheet-round-up-5000-r1`.
- V73: `data/legacy-v73-catalog.json` и `data/legacy-v73-pricebook.js` — копия неизменённых старых 20 цен и 13 допов.
- Сервер по `pricebookVersion` обслуживает V74 и старые V73/V72/ранние версии, не пересчитывая прежние заявки.
- Новая база Квадро 5 м = 505000 ₽. Старый V73 сценарий = 500955 ₽.

## Комплект «Комфорт» — отдельная коммерческая проверка
С прежними допами 113022 ₽ новый расчёт = 505000 + 113022 = **618022 ₽** (без произвольного округления и скрытой скидки). В PR показана точно эта сумма из server/JS/first-paint. **620000 ₽** может быть только отдельным владельческим решением с отражением в расчёте; запрещено писать 620000 только в HTML.
