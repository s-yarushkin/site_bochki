## Установка и откат

`ops/v74-content-release.ps1 -SourceSha <точный SHA>` получает pinned git-архив, выполняет локальную приёмку, сверяет SHA256 передачи и запускает новый `ops/v74-content-install.py` через SSH/sudo владельца. Установщик:

1. Проверяет действующий V73, точные blobs app/relay и совместимость цен.
2. Копирует действующие релизы; сохраняет production OG, legal/contact, внешние CSS и весь текущий конфигуратор. Реестр фотографий правит только в двух ссылках одной обложки; gallery — в одной ссылке. Проверяет, что другие файлы и все байты фото неизменны.
3. Изолированно проверяет серверный расчёт, делает read-only backup SQLite и реальное восстановление в отдельный файл с проверкой целостности и числа строк.
4. Проверяет отсутствие конкурентных изменений, переключает совместимый API, ждёт health и 401 manager, затем web. Подтверждает девять страниц и изменённые assets по HTTPS.
5. При ошибке возвращает обе ссылки. Live SQLite не восстанавливает поверх новых заявок. Печатает постоянную команду отката из backup-каталога.

Caddy, env, auth, другие сервисы сервера, MAX и live заявки не меняются. Установка выполняется только из PowerShell владельца; DC/Actions для неё не используются.

**Фактический production deploy: NOT_RUN.** SSH из среды недоступен (`Network is unreachable`), подключённый компьютер офлайн. Публикация не объявляется выполненной; окончательная browser-приёмка и запуск установки включены в один подготовленный PowerShell-файл.
