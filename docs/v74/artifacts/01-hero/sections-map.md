# V74-01 · Карта смысловых экранов главной страницы

**Источник:** текущий `index.html` на базе `plan/v74-customer-experience-20261019`; задача #58. Это аналитическая карта, не разрешение менять остальные секции.

**Принцип:** «виртуальный экран» — законченная смысловая сцена с естественной прокруткой, а не обязательная высота `100vh`. Не использовать scroll-snap, fixed CTA вместо hero и clipping длинного контента. На mobile нормальная прокрутка предпочтительнее микрошрифта.

| № | Сцена / селектор | Для чего нужна | Действие и переход | Потенциальная проблема / следующее решение | Высота |
|---|---|---|---|---|---|
| 01 | Hero `.hero` | Сразу объяснить ценность, показать объект, два CTA и 01/02/03 | «Собрать свою баню» → #builder; «Посмотреть модели» → #models | P0: исправить реальную above-fold видимость, зафиксировать браузерные координаты | Desktop target помещается в viewport; mobile естественный scroll |
| 02 | «На дачу — отдыхать» `.pain` | Назвать проблему долгой стройки | Следующий блок — модели | Может дублировать hero; оставить только одну ясную мысль | Высота по тексту |
| 03 | Каталог `#models` | Дать сравнение четырёх моделей и стартовый выбор | Карточка/галерея → выбрать модель → builder | V74-03: связь цены с базой; карточки не обязаны влезать в один viewport на узких экранах | Автоматическая |
| 04 | Базовая комплектация `#base` | Доказать, что входит в базовую стоимость | «Уточнить с менеджером» | Группы длинные; нужен удобный путь из каждой карточки (V74-03) | Автоматическая, без обрезания списка |
| 05 | Skyline `[data-weather-scene=skyline]` | Поддержать атмосферу солнце/пасмурно | Переход к готовому комплекту | Возможный повтор обещания hero; V74-04 решить по ценности, не удалять сейчас | Естественная |
| 06 | Комплект «Комфорт» `#bundle` | Показать конкретный готовый вариант и преимущества | «Выбрать» / «Подстроить под себя» | Проверка единой цены — отдельный контур V74-02; фото без замены | Длинная сцена с прокруткой |
| 07 | Персонализация `#personal` | Показать право выбрать детали без сложного прайса | «Обсудить свою баню» | Не превращать предложения в обещание любой конфигурации | По содержимому |
| 08 | Вечер `[data-weather-scene=evening]` | Эмоциональная связка к практической доставке | Скролл → доставка | V74-04 оценить повтор атмосферных вставок | Естественная |
| 09 | Доставка `#delivery` | Объяснить: привезём собранной или соберём из готовых элементов | «Обсудить доставку» | Отделить доступность способа и отдельные затраты; не обещать бесплатный монтаж | По тексту |
| 10 | Конфигуратор `#builder` | Превратить интерес в предварительную конфигурацию и заявку | 7 шагов → расчёт | V74-06/05; не скрывать preview/сумму и не отправлять лид автоматически | Длинная интерактивная сцена |
| 11 | Разница конструкции `#why-us` | Объяснить качество вне фотогеничности | «Выбрать свою модель» | Типографика и подтверждение фактов — V74-04/05 | Автоматическая |
| 12 | FAQ `#faq` | Снять возражения о сроках, составе, доставке | «Перезвоните мне» | Текст должен совпадать с реальной доставкой; раскрытие keyboard | Автоматическая |

| 15 | Footer `.footer` | Контакты, право, повтор связи | Телефон, callback, legal | Не скрывать на mobile fixed CTA, сохранить SEO и юр. ссылки | Автоматическая |

**Приоритет переработки:** V74-01 hero → V74-03 каталог/база → V74-04 редакторская ценность вставок → V74-06 builder → V74-05 типографика. Остальные сцены в этом PR не меняются.

**Доступность:** текст читается при 200% zoom; порядок DOM = порядок чтения; anchor scroll-margin корректен; sticky header и мобильный CTA не перекрывают фокус/формы.
