# Чёрная пятница 2026

Публичный адрес: https://дачапар.рф/blackfriday/ (адрес без завершающего слеша
перенаправляется файловым сервером). Согласованный дизайн — светлая студия,
четыре чёрные бани, художник, нейтральные карточки и оранжевый CTA.

## Цена и срок

Общий источник главной и лендинга: web/campaigns/blackfriday-data.mjs.
40 цен рассчитаны по утверждённым правилам из текущего публичного каталога.
Дополнительные 20 000 ₽ на Делюкс в расчёт акции не включаются.

| Модель | Комфорт | Делюкс |
|---|---:|---:|
| Квадро | 25 000 ₽ | 35 000 ₽ |
| Парус | 30 000 ₽ | 35 000 ₽ |
| Викинг | 30 000 ₽ | 35 000 ₽ |
| Квадро Хаус | 45 000 ₽ | 55 000 ₽ |

Парус 5,5 м Делюкс: прайс 684 000 − скидка 35 000 = от 649 000 ₽.
Скидка действует при заключении договора с 11.11.2026 00:00 по 21.11.2026
23:59:59 МСК. С 22.11.2026 00:00 скидка отключается: зачёркнутая сумма
становится обычной ценой по новому прайсу. До старта лендинг показывает
будущую цену с датой начала, главная — новый прайс без скидки.
Часы уточняются по HTTP Date сервера. Цены обновляются и в уже открытой вкладке.

Зачёркнутая сумма обозначает новый прайс вне акции, а не историческую цену.
Исходные прайсы старого калькулятора и API не переписываются: предложение
акции — отдельное представление в текущем каталоге и на лендинге. При
изменении исходного каталога несовпадающая акция автоматически не применяется.

## Заявки

Используется существующий buildCallback/submitLead → /api/lead → MAX/CRM.
Телефон, MAX, Telegram и WhatsApp проходят действующий контракт. В комментарии
сохраняются акция, место кнопки, модель, размер, комплектация, прайс, скидка,
цена «от» и срок договора. intentContext различает явный выбор, значения
по умолчанию и параметры ссылки. История действий передаётся существующим
механизмом с учётом выбора аналитики. Картинка планировки не отправляется.
Успех отображается только после delivered + analytics.persisted от API.
requestId защищает от повторной доставки; при ошибке доступен повтор отправки.

## Сборка и проверки

scripts/prepare-blackfriday-release.py --baseline снимает актуальные хеши
всего сайта/API и необходимые публичные исходники. scripts/build-blackfriday.py
собирает страницы поверх этой версии, сохраняя действующий первый экран,
планировки, 3D и интеграции. Оригиналы сцен сохраняются в concepts; WebP
кодируется без потерь, совпадение декодированных RGB проверяет сборка.

Пройдены 30 тестов: цены, границы МСК, контракт всех каналов, API с доставкой
через заглушку и дедупликацией, происхождение выбора и базовый прайс.
В браузере проверены модели/размеры, мобильная сцена, сравнение,
локальная отправка, экран успеха и повторное открытие формы, главная и её цены.
У локального сервера база в памяти, настоящие сообщения менеджерам не уходят.

## Публикация и откат

Пакет — .local/blackfriday-20261110. Подготовка:
prepare-blackfriday-release.py → upload-blackfriday-release.py (preflight).
Один интерактивный запуск scripts/publish-blackfriday.ps1 запрашивает sudo
только после preflight. Задание отделено от SSH и сохраняет статус/отчёт.

Установщик сверяет полный исходный сайт/API, разрешает только 16 файлов
страниц/ресурсов акции, проверяет 40 цен и четыре канала на действующем
валидаторе без записи заявок. Переключается только symlink сайта.
API, БД, systemd, Caddy, порты, аккаунты и MFA не меняются.

После переключения проверяются публичные SHA, /blackfriday, MIME изображений,
отказ невалидной заявке, защита кабинета и неизменность всех 128 файлов API.
При ошибке symlink возвращается автоматически. Состояние и квитанция сохраняются
на сервере в /var/backups/dachapar/BF-<id>/, локально — deployment-result.json.
Для ручного отката вернуть symlink сайта на previous_web из state.json;
базу и API восстанавливать из старой копии не требуется.
