**Дата:** 10.10.2026. **Целевая ветка:** `feat/garant-bani-v5-final-site-sun-rain`, основана на QA-проверенном `feat/garant-bani-v5-dual-theme-foundation` (PR #9). **Текущий статус:** CODE READY FOR MEDIA IMPORT / TESTS NOT YET EXECUTED ON FINAL BRANCH / NO DEPLOY.

## Включено

1. Полный визуальный слой SUN (светлая, тёплая дача) и RAIN (тёмный лесной уют); переключатель в отдельной панели над hero, не на фотографии.
2. Фотографический hero, 4 модели, комплект «Комфорт+», эмоциональный блок, реальные примеры объектов и интерьер, адаптивные карточки и responsive-конфигуратор.
3. `assets/js/media-v5.js` — декларативная карта картинок. Hero имеет две версии: дневное реальное фото GBV5-85FFBEBE5 и **художественно обработанный дождливый вариант**. Для каждой другой модели фото **ОДИНАКОВОЕ** в SUN и RAIN: никаких придуманных дополнительных фотографий. Данные выбранной модели/опций/стоимости сохраняются.
4. `assets/css/v5-finish.css` — третий CSS слой поверх `site.css` и `themes-v5.css`, без изменения UI движка.
5. Пакет `GB-V5-SUN-RAIN-release-media.zip` (12 реальных / тематически обработанных WebP, около 2,1 МБ), подготовлен отдельно от GitHub: пользователь загружает пакет в `assets/media-v5/` из `Downloads`. Защитный `MEDIA-MANIFEST.json` содержит SHA-256 каждого файла.
6. `tests/v5-final-media-contract.test.mjs` + расширенный `tests/browser_smoke.py`: физическое наличие файлов, контроль SHA-256, загрузка/целостность изображений, правило 4 одинаковых карточек, реальная смена hero SUN/RAIN, сохранность цены и всех полей forms.

## Инварианты, которые НЕ менять

- `data/pricebook.js` и `assets/js/quote-engine.js`: **DEMO_ONLY**. Отображать фактическую существующую базу; не копировать выдуманные цены из дизайн-макетов.
- `POST /bani-preview/api/lead` и логика приёма по MAX: оставить как есть. Браузерный smoke **перехватывает POST** и не проверяет живую отправку.
- `manager.html`, manager auth, SQLite, systemd, два менеджера: не изменять.
- Работающий `https://дизайн-завод.рф/`, его relay и любые другие проекты: **не трогать**.
- `noindex,nofollow` и закрытый режим preview: сохранить.
- Фото и модель: страница Tilda не является независимым доказательством принадлежности конкретной модели; происхождение и права на публичный релиз требуют подтверждения.
- Юридические документы `privacy.html`, `consent.html` содержат **не заполненные реквизиты оператора**. Публичные продажи запрещены до их принятия.

## Порядок включения медиа и проверок

1. Скачайте из диалога `GB-V5-SUN-RAIN-release-media.zip` в папку Windows `Downloads`.
2. В отдельном чистом checkout именно этой ветки запустите `powershell.exe -NoProfile -ExecutionPolicy Bypass -File ops/v5-stage-media-and-qa.ps1`. Не требуется вводить token, sudo или пароли сервера.
3. Скрипт извлекает 12 WebP в `assets/media-v5/`, проверяет JSON-манифест и SHA-256, запускает `npm run check`, `py -3 tests/browser_smoke.py` на 1440/390/320 px и `py -3 tests/manager-browser-smoke.py` на тех же ширинах, фиксирует один commit только media и push только этой ветки. На любой ошибке STOP без деплоя.
4. После PASS — создать сборку preview **из точного head SHA**, проверить перечень файлов и хеши media. Серверная публикация отдельно, только для `/bani-preview/`, со свежим preflight и rollback.
5. Проверить через серверный GET (401/200) HTML, CSS, JS, WebP; проверить неиндексацию, отсутствующие 404, абсолютные пути, HTTPS, графику на реальном браузере.
6. Локально на сервере, без модификации данных, проверить сервис relay active, SQLite path/permissions, MAX health; **реальный тест заявки** только с разрешения владельца, с известной тестовой записью.
7. Сделать snapshot current/previous и опубликовать атомарно исключительно статический preview; после переключения проверить неизменность `/`, `/api/lead` Дизайн-Завода и всех иных путей.
8. Откат — вернуть сохранённый `/srv/sites/garant-bani-preview/current` на точный предыдущий релиз. Не менять `/srv/sites/design-zavod/current` и Caddy без необходимости.
