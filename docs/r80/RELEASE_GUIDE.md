# R8.0 · «Дача Пар» — новая структура без переноса калькулятора

**Главная**: Hero → 4 модели → «База / Комфорт» → включённое оснащение → **оригинальный калькулятор и все CTA** → два фотопревью → прежние эмоциональные секции и SEO-информация. Полные фото и схемы вынесены на страницы соответствующих моделей; `/raboty/` содержит девять реализованных объектов.

## Что внутри

- `transform.py` — стандартная библиотека Python, точечная перестановка исходных HTML-секций с сохранением самих блоков; **не меняет app.mjs**.
- `install.py` — серверный preflight, stage, отдельная guarded activation с атомарным WEB-переключением и автоматическим rollback при публичном hash-smoke.
- `SITE_MAP_R80.md` — точная карта URL и пользовательских переходов.
- `tests/` — локальные структурные и изолированные браузерные проверки.
- `preview/` — локальный макет на основе последнего подтверждённого unified release (ВАЖНО: страницы Квадро/Викинг/Парус в макете имеют тестовые базовые шаблоны; при серверной сборке берутся исходные файлы **текущего сайта**).

## Почему нельзя сразу деплоить ZIP

Активный полный release находится только на сервере и включает часть HTML-моделей, отсутствующую в предыдущем ZIP из 81 файла. Поэтому **не** заменяем сайт локальной копией с неполными исходниками. Скрипт `--stage` копирует точное полное дерево действующего release и меняет только заранее разрешённые 9 HTML/CSS/JS/XML файлов. Продакшен-активация `--activate` будет разрешена **только после** браузерной проверки именно серверной stage-сборки.

## Команды на сервере (для владельца через PowerShell/SSH)

`sudo python3 install.py` — только preflight, ничего не меняет на сайте.

`sudo python3 install.py --stage` — создаёт новую неактивную папку в `releases`; symlink `current` не меняется.

`sudo python3 install.py --activate /srv/sites/dachapar-preview/releases/CJM-R80-...` — только после одобренной браузерной приёмки. Проводит повторный source SHA preflight, сверяет stage-inventory, затем одно переключение WEB. При любой ошибке публичной проверки откатывает symlink. API, MAX, SQLite и менеджерский кабинет не трогаются.
