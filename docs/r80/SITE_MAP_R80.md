# Дача Пар · утверждённая структура R8.0 (22 октября 2026)

## Принцип
**Главная = выбор модели + цены/CTA + существующий калькулятор.** Из неё удаляются ТОЛЬКО полные фотосерии и планировки; основной `app.mjs`, формы и pricebook не меняются. Никакого отдельного `/podbor/` и нового калькулятора в этой задаче.

## CJM — короткие маршруты

1. «Не знаю, какую баню»: главная → 4 модели → модель → её фотографии и/или планы → «Рассчитать мою баню» (открывает `/?model=...#configure`) → существующая форма.
2. «Хочу Квадро Хаус»: главная → карточка Квадро Хаус → `#photos` (парная с большим окном) или `#plans` → расчёт и контакт.
3. «Хочу посмотреть примеры»: меню «Реальные бани» → `/raboty/` → фильтр → конкретный объект → страница нужной модели + фотогалерея.
4. «Хочу узнать цену»: герой/меню/карточка → `/#configure` (остаётся прежний функционал); никаких промежуточных страниц.

## Границы материалов
- Объект фотосъёмки принадлежит **только** одной модели и имеет свой `objectId` и фотосерию.
- Планировка принадлежит **только** модели и известному размеру; она не соединяется автоматически с отдельной реальной фотографией.
- Цена относится **только** к расчётной модели/размеру в действующем прайсе. Ни одна карточка выполненной бани не содержит выдуманной цены, габаритов или плана.
- На страницу Квадро/Викинг не подставлять чужие фотографии, пока нет проверенной серии.
- QH 6×6 **не** приписывать большое окно парной на фото.

## Старые ссылки и SEO
- `/#models`, `/#packages`, `/#configure`, `/#builder`, `/#bundle`, `/#personal`, `/?model=...#builder` остаются без изменений логики.
- Старые `/#parus-photos`, `/#parus-layouts`, `/#qh-photos`, `/#qh-layouts` получают клиентский переход к модельным страницам.
- Canonical всех старых URL не меняется, `/raboty/` получает собственный canonical и вход в sitemap.xml; robots/региональные/юридические URL не меняются.
- Меню «Фото бань» меняется на ссылку `/raboty/` и на desktop, и на mobile.

## Деплой и безопасность
- Трансформируется **именно активное дерево WEB** `GALLERY-UNIFIED-20261022-parus-qh-v1-1792680175428407103`, не ветка GitHub с устаревшей базой.
- Protected: `app.mjs`, `quote.mjs`, `lead-client.mjs`, pricebook, API, менеджер и его TOTP, SQLite, MAX. Ни один файл за пределами WEB не изменять.
- Сначала read-only source SHA → создание изолированного stage → diff/inventory и browser QA → только по подтверждённой приёмке атомарное переключение WEB + публичная hash проверка и откат.
- Новая `/raboty/` и карточки не заявляют несуществующую поддержку фото Квадро/Викинг.
