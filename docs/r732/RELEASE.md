## Выпуск

ops/r732-seo-text-release.ps1 принимает -SourceSha и необязательный -Deploy. Без -Deploy — только чтение и серверная проверка. С -Deploy: проверка исходников → копирование текущего WEB → проверка всех защищённых файлов → атомарное переключение → HTTP-проверка 24 HTML, sitemap и Яндекс-файла. При сбое проверки возвращается прежняя версия, если текущую ссылку не изменил другой релиз.

Установщик не перезапускает сервисы, не читает SQLite и не вызывает MAX. Старая версия остаётся доступной для отката. Если активная версия изменилась, выпуск останавливается с конкретной причиной; нельзя обходить проверку путём подстановки чужих SHA.

Для чтения кабинетов поиска/Метрики или получения Wordstat требуются отдельные фактические данные. Их отсутствие не является причиной задерживать этот контентный выпуск.
