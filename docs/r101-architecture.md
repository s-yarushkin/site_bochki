# ДачаПар с нуля: продающая архитектура R101

28 октября 2026. Новая архитектура и работающая отдельная сборка. Действующий R100 не заменён. Цель: понятное предложение для посетителя из Яндекс Директа и больше предметных обращений, которые могут стать договорами. Рост конверсии пока является гипотезой.

## Главный выбор

**Продаём продуманную готовую баню, а не конструктор доплат.** Единственная публичная комплектация — Комфорт. Все 20 цен и её состав сохранены. Делюкс убран из нового интерфейса. Его исторические данные и заявки остаются совместимыми с кабинетом.

Большой калькулятор не нужен. На карточке человек выбирает **модель + размер**, видит точную цену Комфорта и обращается за **расчётом доставки и работ для участка**. Нельзя выдавать сумму бани за полную стоимость с логистикой. Выбор планировки не входит в расчёт и не является условием обращения.

Главная обещает отдых и снимает сложность выбора; модельная посадочная отвечает на конкретный рекламный запрос; страницы второго уровня дают доказательства. Цена, состав и телефон доступны сразу, без прохождения квиза.

В сборке 29 маркетинговых маршрутов, 404 и четыре сохранённых служебных HTML. Старые `/komplektacii/` и `/ceny/` ведут в новую логику. Удалены из поставляемого набора изображения ошибочных p9/p11 и их зеркал; ссылка на такую схему показывает объяснение и доступные альтернативы. Размеры Хауса 4×4 и 5×4 продолжают продаваться по прежним ценам.

## Многослойность содержания

1. **Быстро понять:** главная, цена, четыре модели, очевидный следующий шаг.
2. **Убедиться:** модельная страница, реальный фасад и интерьер, полный состав, открытая таблица размеров.
3. **Проверить под себя:** необязательные планировки, особенности участка, вопрос менеджеру.
4. **Довести до заказа:** в кабинет и уведомление приходит выбранная модель/размер/Комфорт, контакт, населённый пункт, цель обращения и точный фотоориентир. Окончательный расчёт и договор — работа менеджера.

Многослойность изображения: цельная реальная парная, независимый прозрачный ближний слой берёзы, типографика на своей светлой поверхности. Схемы и цены не прячутся за эффектами. Блок деталей связывает атмосферный кадр с точными включёнными предметами. На мобильном сокращённый ход сцены и нативная горизонтальная последовательность.

## CJM и посадочные для рекламы

| Намерение | Посадочная | Что нужно понять | Доказательство | Действие |
|---|---|---|---|---|
| «Готовая баня для дачи» | Главная | Это оснащённая баня, цены открыты | Четыре модели + состав Комфорта | Выбрать баню |
| «Купить Квадро 5 метров» | `/bani/kvadro/?size=500` | Цена именно моего размера 485 000 ₽ | Совпадение карточки, таблицы и формы | Рассчитать доставку |
| «Баня с комнатой отдыха» | Модельная / планировки | Где отдыхать и хранить вещи | Проверенная схема, реальные интерьеры | Обсудить планировку |
| РСЯ, эмоциональный интерес | Главная | Хочу такой отдых; можно разобраться без звонка | Парная, ритуал, затем открытая цена | Выбрать модель / сохранить |
| Сравнивает предложения | Комфорт / сравнение | Что я получаю за сумму | Точный список и отдельные расходы | Получить расчёт для участка |
| Вернулся с семьёй | Сохранённая ссылка модели/размера | Мой выбор на месте, цена актуальна | Резюме модели без старых опций | Продолжить к расчёту |

Не обещать в объявлении панорамное окно в стандартном Комфорте. Не вести все модельные запросы на одну общую главную. Не смешивать результат поиска и РСЯ при оценке качества заявок. Возраст, доход и мотивации аудитории не выдуманы: сегментация по задаче покупки — проектная гипотеза, уточняется по обращениям и интервью.

## CTA: одно действие на одно намерение

| Место | CTA | Что происходит | Контакт |
|---|---|---|---|
| Первый экран | Выбрать баню | Переход к четырём моделям | Нет |
| Рядом с обещанием | Что уже входит | Полный состав Комфорта | Нет |
| Модель / размер | Рассчитать доставку | Форма с выбранной баней и точной ценой | По действию |
| Карточка | Сохранить выбор | Ссылка или TXT с моделью/размером | Нет |
| Фото объекта | Хочу похожую | Заявка с каноническим object/photo ID | По действию |
| Планировка | Обсудить планировку | Схема как пожелание, без изменения цены | По действию |
| Нужна помощь | Помогите выбрать | Честный запрос без выдуманной модели | По действию |
| Отправка | Получить расчёт для участка | Согласие, сохранение и доставка по существующему контракту | Да |

Форма не появляется сама. Без модели действующий API допускает обратный звонок; выбранная модель позволяет выбрать MAX и другие существующие каналы. Публичного `maxChatUrl` в настройках нет: не подставляем вымышленную ссылку. Текущий MAX-процесс уведомления и кабинет сохраняются.

## Платформа и данные

Новая оболочка — статический HTML/CSS и небольшие ES-модули. Все основные тексты, таблицы цен и схемы есть в HTML; серверный рендеринг не нужен для чтения. Генератор `r101/build.py` создаёт отдельный `output/r101-site`, не редактирует `web` или сервер.

Источники истины: защищённый `catalog-pricebook.json`, существующие `quote.mjs`/`r85-pricing.mjs`, канонические `photo-references.json`, существующий `/api/lead`. Ценовой пакет в API по-прежнему имеет историческую версию R93: название версии не является рекламной комплектацией. Полезные модули R100 сохраняют проверку телефонов, согласия, происхождения обращения, атрибуции и серверного подтверждения.

Рекламные query-параметры сохраняются. В Метрику не передаются телефон, имя, населённый пункт и текст вопроса. Успех засчитывается только при подтверждённых `persisted` и `delivered`; открытие формы не является лидом. Сервер остаётся ответственным за фактическую цену, защиту, дедупликацию и доставку.

## Очередность запуска и измерения

| Этап | Что должно получиться | Критерий перехода |
|---|---|---|
| 1. Архитектура и кандидат | Новый сайт в отдельном предпросмотре | Открытые цены, ясный Комфорт, реальные доказательства, удобная форма |
| 2. Приёмка | Desktop/mobile, ошибки/повторы, все 20 серверных цен, защищённые файлы | Контекст и цена не теряются, ошибочные схемы не показаны |
| 3. Выпуск | Финальный пакет, копия текущего WEB, переключение только WEB | Вернуть индексирование, проверить публичные URL и настроенный приём без потери кабинета/MAX |
| 4. Директ | Раздельные группы по намерениям и посадочным | Проверены цели и атрибуция; квалификация менеджером записывается |
| 5. Улучшение по данным | Целевые изменения текста/доказательств/CTA | Сравниваем стоимость квалифицированного обращения и договора, причины отказов |

Пока кандидат специально содержит `noindex` и запрет в robots. Это предотвращает преждевременное индексирование предпросмотра; его нельзя копировать на production без процедуры выпуска. Рекламные кампании, бюджеты и CRM-статусы не менялись. Для подтверждения эффективности нужны фактические расходы, обращения и договоры; красивый дизайн сам по себе не подтверждает рост продаж.
