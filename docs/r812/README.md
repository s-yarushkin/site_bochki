## Порядок безопасного внедрения

1. Сохранить этот комплект в Downloads, распаковать.
2. Запустить предконтроль без записи: `powershell -NoProfile -ExecutionPolicy Bypass -File .\DachaPar_R812_Visual_Compare.ps1`.
3. Подготовить stage, без переключения: `powershell -NoProfile -ExecutionPolicy Bypass -File .\DachaPar_R812_Visual_Compare.ps1 -Stage`.
4. На stage проверить 390/768/1366/1920px, реальные фото, переходы, отсутствие горизонтального скролла, корректные URL/цену, и наличие доступного блока точного сравнения. **Не считать локальные структурные проверки браузерной приёмкой stage.**
5. После отдельного согласования и успешной визуальной приёмки: `-Deploy -StagePath <точный путь из stage> -Approval 'R812_VISUAL_COMPARE_APPROVED'`. Сценарий атомарно переключает только WEB с GET+SHA и откатывает в R8.1.1 при ошибке.
6. Для статуса: `-Status`. Для отката только этого релиза: `-Rollback` (не откатывает чужие релизы).

Вся работа выполняется через Windows PowerShell; GitHub Actions и Remote Desktop Commander не нужны. За одно выполнение один удалённый `sudo`, пароль не хранится и не отключается.
