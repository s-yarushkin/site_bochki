# R8.1.2 — браузерная приёмка непубличного stage

Скрипт проверяет точный stage `CJM-R812-VISUAL-SELECT-20261023-1792760695767877252`, который **не активирован**, а опубликованным остаётся R8.1.1 `CJM-R811-HERO-COPY-20261023-1792759364955844292`.

Скачайте архив в `Downloads`, распакуйте и выполните PowerShell:

```powershell
$dir = "$env:USERPROFILE\Downloads\DachaPar_R812_QA"
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\DachaPar_R812_Browser_Stage_QA_20261023.zip" -DestinationPath $dir -Force
powershell -NoProfile -ExecutionPolicy Bypass -File (Join-Path $dir 'DachaPar_R812_Stage_Browser_QA_20261023.ps1')
```

**Что делает**: SSH читает три HTML из непубличного stage, проверяет SHA-256 из точного R8.1.2 манифеста, затем запускает Windows Chrome/Edge в безголовом режиме через CDP на случайном локальном порту. Изменённые HTML отдаются только локально. Неизменённые CSS/изображения/JS и страницы моделей подтягиваются только через HTTPS GET с действующего сайта. Любые браузерные попытки POST блокируются; рабочая система заявок, API, база, MAX, кабинет и production WEB не изменяются. `sudo` не требуется. Возможны обычные SSH-ключи/пароли, если у пользователя не настроена авторизация по ключу.

**Проверки**: фотографии всех четырёх моделей реально загружаются и отображаются, цены 390/415/450/649 тыс. ₽, переходы из карточек, отсутствие ссылки сравнения вверху главной, второстепенная ссылка внизу каталога, скрытая по умолчанию таблица и её раскрытие, canonical, ширины 390/768/1366/1920, переполнение, ошибки JS, критические ошибки загрузки, запрет внешних запросов и POST. Для страницы сравнения сохраняются PNG 390 и 1366 px в `%TEMP%`. Выходы `R812_PASS=...` / `R812_FAIL=...`, финальный `R812_BROWSER_QA=PASS|NO_GO` и подробный JSON в `%TEMP%`.

**Ограничения**: QA в Chromium — техническая приёмка, а не замена человеческого осмотра изображений/выравнивания. Посмотрите две сохранённые PNG перед решением об активации. Не запускайте `-Deploy` до разбора всех FAIL и проверки скриншотов. Если сайт в production сменится на другой релиз в момент теста, скрипт остановится на защите от расхождения исходника; не запускайте проверку поверх другого релиза.

Скрипты проверены локально по SHA/структуре и синтаксису Node; **полный реальный Windows/browser тест ожидает выполнения пользователем**. Не считать непроверенные случаи PASS.
