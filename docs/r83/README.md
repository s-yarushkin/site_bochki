Утепление пола 50 мм, шкаф и рундук **НЕ** приписаны стандартному Комфорту — они являются дополнениями Делюкс для Квадро 5 м.

### Что не входит

Публикация на production в одном запуске. Первый этап — **только STAGE**, без переключения публичного сайта. Браузерная и визуальная приёмка stage обязательна перед отдельным допуском на публикацию. Система не отправляет никаких заявок и не трогает API/SQLite/MAX.

## Запуск

Сохранить `DachaPar_R83_Copy_Comfort_Stage_Kit.zip` в `Downloads`, распаковать в `Downloads\DachaPar_R83` и запустить `DachaPar_R83_Copy_Comfort.ps1 -Stage`.

Ожидать `R83_STAGE=PASS`, `R83_WINDOWS_STAGE=PASS`, путь `CJM-R83-COPY-COMFORT-20261024-...`. Скрипт пользуется одним SSH-вызовом с `sudo` после SCP и проверки архива.

После запуска посмотреть `R83_WORK_PROGRESS` по каждой группе и список `R83_EDITORIAL_AUDIT`. Все статусы NOT_FOUND и сохранённые границы цен анализируются перед публикацией. Публиковать старые релизы и повторять `-Stage` для их перезаписи нельзя.
