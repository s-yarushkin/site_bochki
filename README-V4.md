# Гарант Бани · прототип v4

Адаптивный статический сайт-конфигуратор с демонстрационными ценами и скидками. **Не является коммерческим предложением. Заявки не отправляются.**

## Локальный запуск

```bash
python -m http.server 8080
```

Открыть http://localhost:8080/ из корня репозитория. Для тестов нужен Node.js 22+:

```bash
npm test
python tests/browser_smoke.py
```

Browser smoke использует Python Playwright и локальный Chromium; при запуске вне текущей тестовой среды путь к браузеру в скрипте потребуется настроить.

## Структура
- `index.html` — UI и семантическая разметка;
- `assets/css/site.css` — responsive дизайн;
- `assets/js/app.js` — интерфейс и события;
- `assets/js/quote-engine.js` — чистый модуль расчёта;
- `data/pricebook.js` — демомодели, цены и опции;
- `assets/images/` — две реальные фотографии серии Квадро и SVG-заглушка; остальные фото пока заглушены;
- `tests/` — математические, структурные и браузерные проверки;
- `docs/GARANT-BANI-TZ-V4.md` — подробное ТЗ.
