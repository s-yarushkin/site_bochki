# ДачаПар — сайт и выпуск R100

Рабочий сайт: https://дачапар.рф/. Ранее в репозитории использовались название «Гарант Бани» и старые прототипы; текущие исходники находятся в `web/`.

R100 соединяет выбор модели, планировки, зеркала, комплектации и фотоориентира с расчётом и обращением менеджеру. Формулы и актуальный прайс R99 не изменены. Подробности, проверки и ограничения: [docs/r100-implementation.md](docs/r100-implementation.md).

## Квиз быстрого подбора

Три вопроса → подбор по 41 планировке v04 → предварительная цена на основе действующего «Комфорта» → предложение отправить подробные планировки, комплектации и цены. Правила подбора, коды схем, 24 сценария, доплаты за новые помещения и печи, ограничения расчёта и ссылка на рабочий Google-калькулятор описаны в [спецификации квиза](docs/quiz-selection-and-pricing-2026-10-31.md). Внешний вид, тексты трёх экранов, триггеры, изображения, мобильное поведение и правила конверсии — в [UX/дизайн-спецификации](docs/quiz-ux-design-2026-10-31.md). **Квиз пока не внедрён на сайт; цены планировок предварительные.**

## Проверки

Node.js 24 и Python 3, без установки npm-зависимостей:

```powershell
npm test
python scripts/check-public.py
```

Для локального сервера и сквозных тестов необходима приватная копия действующего API в `.local/api-baseline/`: исходные файлы, публичные и исторические прайсы, без токенов и реальных обращений. Эта папка не публикуется. Владелец может восстановить её из своих архивов командой `python scripts/restore-r99-baseline.py --api-only`.

```powershell
npm run test:api
npm run dev
```

Тестовый сервер слушает только `127.0.0.1:4173`, использует SQLite в памяти и заглушку отправки. Никакие сообщения менеджерам не отправляются; аналитика на localhost отключена.

## Выкладка

```powershell
python scripts/build-release.py
```

Сборка требует `.local/r99-baseline-hashes.json` — проверенные контрольные суммы действующего сайта. Пакет появляется в `output/R100-CRO-…`. `R100-Deploy.ps1 -Mode Check` только проверяет, `Stage` создаёт копии выпусков, `Apply` переключает сайт и API. Последние два режима требуют sudo на сервере. Сначала проверяются исходные версии и хеши; при чужом изменении установка останавливается. База, токены и приватные прайсы в пакет не входят. Откат возвращает код и сохраняет новые обращения.

Данные внутренних исследований и производственные документы в этот репозиторий не добавляются.
