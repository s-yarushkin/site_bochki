## Сборка и просмотр

Из корня implementation, Python с Pillow и BeautifulSoup; bs4 в этом workspace находится в .local/python:

```powershell
python r101/build.py
python r101/verify.py
node --test tests/r101.test.mjs tests/journey.test.mjs tests/analytics.test.mjs
$env:DP_TEST_PORT='4174'
$env:DP_WEB_ROOT='output/r101-site'
node scripts/dev-server.mjs
```

Открыть http://127.0.0.1:4174/. Локальный сервер использует SQLite в памяти и заглушку уведомлений, не вызывает реальные мессенджеры. Исходные web/ и API сборкой не меняются.

## Выпуск

Кандидат output/r101-site закрыт от индексирования. scripts/r101-release.py отдельно формирует пакет для домена с включённым индексированием, проверкой серверного исходного состояния и сохранением 13 защищённых файлов. scripts/r101-remote.py меняет только публичную копию, не перезапускает сервис заявок и не трогает базу. Старый установщик R100 к новой версии не применять.

20 исходных цен Комфорта сохранены. Планировки не участвуют в выборе цены; дополнительные пожелания не добавляют платные опции автоматически. Телефон, юридические документы и кабинет сохраняются. Прямые ссылки моделей с ?size= работают, переход к схемам сохраняет размер.

SCROLL-CRAFT engine и MIT-лицензия включены в vendor без изменений. Точные промпты фотографий — assets/FACADES-PROMPTS.json и assets/PROMPTS.json. Снимки актуальной проверки — output/qa/r101-v3-*.png.
