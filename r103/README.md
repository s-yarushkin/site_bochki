# R103 — поиск, статьи и favicon

Отдельный выпуск поверх стабильного R102. Не меняет цены, комплектацию, личный кабинет, документы, API или интеграции уведомлений.

Сборка: `python r103/build.py`, затем `python r103/verify.py`. Пакет: `python r103/release.py` после получения свежего read-only inventory скриптом `scripts/r101-inventory.py`.

Результат: `output/r103-site/`. Кандидат закрыт от индексации. Локальный просмотр: `DP_WEB_ROOT=output/r103-site`, `DP_TEST_PORT=4187`, `node scripts/dev-server.mjs`. Только локальная память и заглушка уведомлений; настройки production при этом не используются.

Выпуск разрешает индексирование только в установочном пакете, сохраняет стабильную версию, проверяет хеши всех исходных публичных файлов и 13 защищённых файлов, валидирует заявки без отправки и автоматически возвращает прежнюю версию при неудаче публичной проверки.

## Содержание

- 13 переработанных статей с содержанием, сравнительными таблицами, списками подготовки и связанными материалами.
- Четыре региональные страницы с собственным содержанием. Все используют актуальные цены из неизменённого каталога.
- Названия главной, каталога и моделей понятнее описывают товар в поиске.
- Явно добавлен Санкт-Петербург; регион передаётся в действующую форму без изменения её протокола.
- ICO с размерами 16/32/48/64/128/256, PNG 32/48/120/180/192, SVG, apple-touch-icon и версия ссылок для обновления кэша.
- Пять новых иллюстраций встроенной модели; исходники в `r103/assets/`, WebP 640/960/1536 в сборке. На одной странице нет повторяющихся иллюстраций.

## Редакционные ограничения

Нет вымышленных офисов, проектов, отзывов, сроков поставки, авторов-экспертов и производственных достижений. Изображения не выдаются за фотографии выполненных заказов. Схемы сравнения размеров и подготовки участка не являются рабочими планами и не содержат вымышленных строительных норм. На иллюстрации оснащения показаны категории; исполнение фиксируется в заказе.

Технические темы не подменяют инструкцию конкретного оборудования. Основные первичные источники для проверки общих принципов:

- https://support.harvia.com/hc/et/articles/21953036825628-Ventilation-in-the-sauna
- https://www.harvia.com/en/ideas-and-trends/products/tips-for-maintaining-your-wood-burning-heater/
- https://support.harvia.com/hc/lt/articles/22158333579676-Maintaining-your-sauna
- https://yandex.ru/support/webmaster/ru/search-results/favicon
- https://developers.google.com/search/docs/fundamentals/creating-helpful-content

Использование источников Harvia не означает установку печей этого производителя в банях ДачаПар. Марка установленной печи не заявляется без спецификации заказа.

## Проверки

Машинный отчёт: `output/r103-verification.json`. Мобильная проверка всех 32 основных страниц на 320 px: `output/r103-mobile-audit.json`. Дополнительные 21 сочетание страниц и ширин 390/768/1280: `output/qa/r103-breakpoints.json`. Реальные аппаратные клавиатуры и позиции в поиске не эмулируются этим отчётом. Локальная региональная форма прошла сквозной тест с записью в тестовую память и заглушкой уведомлений; реальная заявка не отправлялась.

Перед установкой на сервере выполняется отдельный `--check`, после — проверка всех файлов выпуска через домен и контроль защищённых файлов. Факт готового пакета не равен публикации.
